# callsched — 外呼名单调度库

单进程、串行调用的内存组件，处理活动暂停、全局拒接标记（DNC）与重试期限共同作用下的取号。不处理真实通话；时间由调用方传入整数秒，带时间的调用须按时间单调不减执行。非并发安全。

## 接口

```go
// 以固定的活动、联系人及成员关系初始化。活动数 <= 10，一个联系人可属于多个活动。
// 活动初始均为 Active；每个（活动, 联系人）组合初始可拨时刻 0、尝试次数 0。
func New(memberships []Membership) *Scheduler

// 在 Active 与 Paused 之间切换活动状态。
func (s *Scheduler) SetCampaignState(id string, state CampaignState)

// 设置或解除联系人的全局 DNC 标记。
func (s *Scheduler) SetDoNotCall(contactID string, blocked bool)

// 领取一个当前可拨的组合；没有候选返回 ok=false。
// 成功领取视为拨号开始：立即占用联系人并消耗一次尝试。
func (s *Scheduler) Take(now int64) (Call, bool)

// 结束一次拨号并释放联系人。Resolved 永久结束该组合；
// NoAnswer 且累计尝试不足 3 次时，下次可拨时刻设为 now+7200，否则永久结束。
// 每张票据仅提交一次。
func (s *Scheduler) Finish(ticket Ticket, result Result, now int64)
```

`Take` 返回所有合格组合中按（可拨时刻, 活动ID, 联系人ID）字典序升序的首项。合格 = 活动 Active ∧ 联系人无 DNC 且未占用 ∧ 组合未结束 ∧ 可拨时刻 ≤ now。同一联系人跨所有活动最多一次未完成拨号。暂停与 DNC 只影响后续领取，不撤销已开始的拨号；屏蔽期间可提交 `Finish`，解除屏蔽后原可拨时刻与尝试次数原样恢复。

## 实现与复杂度

核心不变量：**组合在其活动的堆中 ⟺ 未结束 ∧ 联系人未 DNC ∧ 联系人未占用**。每个活动一个带索引的二叉最小堆（堆内按 可拨时刻、联系人ID 排序，支持 O(log n) 任意删除）。

- `SetCampaignState`：O(1)。只翻转活动标志位，不遍历成员、不重建堆；`Take` 直接跳过非 Active 活动的堆。
- `SetDoNotCall`：O(k log N)。屏蔽时把该联系人的 k 个组合从各自堆中删除；解除时按原 `dialableAt`/`attempts` 重新入堆，重试预算不重置。
- `Take`：O(k log N)。活动数 ≤ 10，只比较各 Active 堆的堆顶取全局最小，再弹出并把该联系人其余组合从堆中移除。被暂停、DNC、占用的组合根本不在可选堆顶路径上，无需逐项跳过，也无全量排序。
- `Finish`：O(k log N)。核销票据、释放联系人、按结果更新组合（重试则改可拨时刻，否则标记结束），再把该联系人全部未结束组合重新入堆——其他活动中该联系人的组合立即恢复参与选择。
- 空间：O(N + U)。每个组合任一时刻至多在一个堆中；未结票据数不超过占用中的联系人数；状态切换只移动既有组合，不积累失效条目，总量不随历史操作次数增长。

## 测试

```sh
go test ./...
```

- `scenario_test.go`：确定性剧本——联系人属于两个活动，交错暂停/DNC/失败提交，验证跨活动占用、解除屏蔽后恢复原重试期限、第三次失败终止、时刻恰好到期与并列时刻排序。
- `reference_test.go`：小规模随机操作序列，与测试中每次全量扫描的独立参照器逐步比对 Take 结果及每个组合的尝试/结束/可拨时刻状态。
- `stress_test.go`：10 万成员关系（10 活动 × 1 万联系人，k=10），9.9 万更早到期组合被暂停/DNC/占用挡住、仅 900 个可拨；反复切换同一大活动与同一联系人 DNC 各 10 万次。验证选取结果，并输出各阶段耗时与常驻状态量（堆内/堆外组合数、票据数），证明候选不遗漏、取号不穿过屏蔽前缀、状态不随切换次数膨胀。
